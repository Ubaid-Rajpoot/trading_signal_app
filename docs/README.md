# Documentation

| Document | What's inside |
|---|---|
| [`strategy-spec.md`](strategy-spec.md) | The TDI + structural shift strategy written out rule by rule, with the confirmed definitions of HVB, SHIFT and MS. |
| [`reference/`](reference/README.md) | The original charts and the ICT/SMC book, filed by topic. |
| [`reports/`](reports/) | Saved output of the win-rate studies (generated by `scripts/winrate.py`). |

## Where things live in the code

```
backend/app/core/
  indicators.py        EMA / RSI / ATR / ADX / MACD / TDI ... pure pandas
  swings.py            swing pivots, SHIFT and MS break detection
  strategies/          one file per strategy
    tdi_shift.py         <- the trader's system
    donchian.py          earlier example strategies
    ema_trend.py
    custom.py            editable template
  signals.py           turns rules into a signal + setup state
  winrate.py           30-day win-rate study
  backtest.py          event-driven backtester (stops optional)
  data/
    history.py         paged downloads + CSV cache for long windows
    providers.py       live -> cache -> demo chain for the dashboard
    synthetic.py       deterministic demo feed (offline mode)
```
